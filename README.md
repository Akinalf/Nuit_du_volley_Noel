# Nuit du volley de Noël – site du tournoi

Site à page unique pour le tournoi de volley (rondes suisses, 12 équipes, 3 terrains) :
planning, matchs, classement et finales, mis à jour en direct sur les téléphones.

- `index.html` : la page (lecture libre ; la saisie des scores demande le code des organisateurs).
- `setup.sql` : structure de la base Supabase (lecture publique, écriture protégée par code).

Le code de saisie n'est stocké que dans la base Supabase, jamais dans ce dépôt.
